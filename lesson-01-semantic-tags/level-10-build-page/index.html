Semantic Tags and Landmarks

Semantic tags

Semantic tags give purpose and structure to a website making the page more accessible to the user and more discoverable in an optimized search engine. Some tags require a closing tag; there are tags called void tags that do not.

Landmarks

Landmarks improve content discovery and assist in locating important content faster in optimized search engines. These elements gives a specific label to each section of the code by organizing the elements into a container. Landmarks are similar to semantic tags; they are what is for more accesiblity, where sematic tags are the structure of the written code.
